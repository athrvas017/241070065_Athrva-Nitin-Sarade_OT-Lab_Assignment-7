# Track I Prompt

Implement hand-built quantum algorithms and QML in PennyLane (simulation only):
1. Deutsch-Jozsa algorithm: distinguish constant vs balanced oracle in 1 query.
2. Bernstein-Vazirani algorithm: recover secret n-bit string in 1 query.
3. Grover's search: custom phase oracle and diffusion operator on 8 states showing O(sqrt(N)) query advantage.
4. Quantum Fourier Transform (QFT) and Shor's order finding factoring N = 15 into 3 and 5.
5. Variational Quantum Classifier (PQC) vs classical Logistic Regression and SVM on 2D Moons dataset.
